# User Management System

## About the Project
The User Management System is a full-stack web application developed to manage users and roles. It includes authentication and Role-Based Access Control (RBAC) to restrict access based on user roles.

## Technologies Used
- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Fastify, TypeScript
- **Database:** MySQL
- **Authentication:** JSON Web Token (JWT)
- **Password Security:** bcrypt

## Features
- User Login and Logout
- User Management (CRUD Operations)
- Role Management (CRUD Operations)
- JWT-Based Authentication
- Role-Based Access Control (RBAC)
- Admin and Team Manager Roles
- Protected Routes
- Dashboard with User Statistics and Recent Users
- Settings and Theme Preferences

## Role Permissions
- **Admin:** Can manage users and roles.
- **Team Manager:** Can view users and roles but cannot perform restricted administrative operations.

## Project Structure
- `backend/` – API, authentication, business logic and database operations
- `frontend/` – React user interface
- `.gitignore` – Excludes environment files and unnecessary folders from Git

## Getting Started
1. Clone this repository.
2. Install the backend dependencies.
3. Configure the database and environment variables.
4. Start the backend server.
5. Install the frontend dependencies.
6. Start the frontend development server.
